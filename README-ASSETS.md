Assets for RPG GUI

Place image files in the `assets` folder at the project root.

## Supported Files (optional):

### UI and General Assets
- `icon.png` — window icon (recommended 64x64)
- `battle.gif` — animated GIF for battle scene (will be used if present)
- `attack.png`, `defend.png`, `skill.png`, `item.png`, `flee.png`, `shop.png`, `save.png` — small button icons (recommended 24x24)

### Background Assets (`assets/backgrounds/`)
- `background.png` — default background
- `dungeon.png` — dungeon environment background

### Enemy Assets (`assets/enemies/`)
- `goblin.png` — goblin enemy sprite
- `goblinarcher.png` — goblin archer enemy sprite
- `orc.png` — orc enemy sprite
- `darkmage.png` — dark mage enemy sprite
- `dragon.png` — dragon enemy sprite

### Character Assets (`assets/players/`)
- `warrior.png` — Warrior character sprite
- `mage.png` — Mage character sprite
- `archer.png` — Archer character sprite

If no images are present, the GUI will fall back to animated ASCII art.
